## 可以验证什么

注册后直接聊天；独立云端授权；有限偏好学习、修正、忘记；显式加密保存话题或草稿、重登恢复、完成或移除；私密试答的三种配置和本人分项评价；停止、重试、撤权以及临时模式。

本包不含 UE 游戏、授权未确认的 Ecy 模型及预览图，不是完整游戏或完整 3D 分身。未提供本机模型时，外观页面明确显示“外观暂不可用”，不再固定显示已载入或 100%。可以局部重试或继续文字对话；加载超过 20 秒会结束等待，晚到模型不会恢复已过期预览。文字代表功能不依赖这些模型。本批没有补造替代人物模型，也没有改动原始资源。

旧问卷仍保留在原账户里。外观、个人主页、社交和伴生窗口不再用旧问卷状态推断数字代表“初始化中”；资料为空不会阻止开始对话。外观、声音和行为的后续能力明确标注规划中。

第六批补齐安全暂停反馈：角色扮演、翻译、引用或恢复草稿触发暂停时，界面如实显示“本次对话已暂停偏好学习”，模型失败也不误报“学习中”。暂停仅在当前账户会话中保留，不写入画像、账本或来源原文；清空本次对话后恢复原学习模式，已有记忆与输入框草稿保留。未授权、关闭/只读或临时模式仍优先显示对应状态。

第七批在现有版本上改进 iOS 风格材质与体验：玻璃集中在导航和操作层，正文减少模糊嵌套；导航分组、SVG 控件、iOS 风格开关、按压反馈与渐进说明统一。关键授权、撤回限制与临时模式仍可直接访问，不改变账户、学习、存储或模型规则。仍为 Windows 应用，不是苹果原生 Liquid Glass。详细设计与验证边界见 `UI_APPLE_GLASS.md`。

第八批在导航侧栏、分段栏和聊天输入区增加实际局部背景位移、边缘高光与指针反馈。折射只发生在圆角内缘，文字、输入控件和 3D 画布不参与变形；没有增加用户数据采集或修改授权规则。清晰/高对比模式关闭效果，减少动态效果停止指针跟随。实际打包程序的条纹像素对照已通过：边缘平均 RGB 通道差约 5.16，中心差为 0；这验证当前材质发生折射，不代表原生苹果效果或跨显卡性能认证。见 `UI_LIQUID_GLASS.md`。

第九批保留第八批材质，减少高频指针布局读取，并补齐取消、触摸、滚动、缩放和失焦时的高光清理。240 个同步测试事件从基线 240 次布局读取降为 1 次，两次位置写入且零贴图重编码；不能将此解释为 239 次强制重排或帧率提升倍数。位移、隐藏及材质失效三个帧前竞态也有实际打包程序回归。详见 `UI_LIQUID_GLASS_INTERACTION.md`。

第十批在玻璃达到本机验收标准后回到数字代表主线：停止生成不再重置临时模式或学习暂停；临时状态响应隐藏长期正文而不删除原资料；整页刷新或主渲染进程退出会结束当前登录，并使旧任务失效。同文档与子框架不误登出，重新登录不重新授予云端处理权限。没有新增自动登录、完整历史存储或临时模式跨登录恢复。详见 `REPRESENTATIVE_PRIVACY_SESSION.md`。

## 手工验收

1. 先核对程序旁的 `.sha256` 文件。未签名可能触发系统提示；不要为了运行它关闭系统防护。若系统阻止或出现风险提示，停止并反馈。
2. 正常双击运行会使用现有的 `%APPDATA%\echoverse-launcher` 账户目录，与旧版本共用本机数据。自动测试使用隔离临时目录，不等于正常运行自动隔离。首次手工试用前备份自己的本机账户目录，不要同时运行旧、新版本。
3. 本包不含模型密钥。若本机已有 DeepSeek 配置，会按现有规则读取；不需要把密钥发给助手，也不要放进程序包或 GitHub。注册账户不等于同意云端处理，学习同样默认关闭。
4. 没有密钥时仍可验证本机草稿保存、重登恢复及删除。需要生成回复时，先确认本机配置与费用承担，再由本人明确开启云端处理、点击发送。每个私密试答配置分别产生一次请求，完整三配置比较需要三次点击；本批自动验收没有真实模型调用。
5. 私密试答可以先填写不上传的对照答案，再生成候选表达。分别判断事实、风格、选择及帮助程度。评分仅留本轮，不训练画像、不落盘，不证明人格复刻或意识上传。
6. 打开“虚拟分身”：本包缺少人物模型，预期显示可恢复错误。点击“重试外观”只重建外观，不刷新软件。先在聊天输入一段未发送草稿，再切换外观、重试并返回“继续文字对话”，草稿应保持不变。自动成功分支使用临时自制几何体，不表示验收包已包含该几何体或人物模型。
7. 学习仍默认关闭。如本人已确认模型配置、云端处理及费用，可以开启学习后发送明确的角色扮演、翻译或引用情境，检查暂停说明。之后的台词不会成为本人偏好。先在输入框留下未发送文字，再清空本次对话，应恢复原学习模式且草稿不变。此步骤会产生本人主动发送的真实模型请求；自动回归使用隔离模拟，不要求手工消费配额来证明机制。
8. 检查玻璃/清晰切换：玻璃模式下，导航、分段栏和输入区有克制的边缘光；鼠标经过时边缘光随位置变化。滚动、缩放或窗口失焦后，旧的指针位置高光应清理；继续移动鼠标后恢复跟随。平坦背景上折射不明显是正常现象，正文不应扭曲。清晰模式关闭折射、透明与模糊，不丢失任何控件。Tab 定位到“学习范围与保存方式”，用 Enter 展开和收起；文字说明仍保留。欢迎空态的建议只填写输入框，不发送消息。系统高对比模式使用原生 checkbox 和系统颜色。
9. 检查临时模式：开启后，界面显示“长期记忆已隐藏”，不展示偏好、来源和待续正文；停止生成不应退出临时模式。明确关闭后回读原资料，不把隐藏解释为删除。若要主动刷新，先按需保存草稿；整页刷新结束登录且不恢复聊天，重新登录后原有加密偏好/待续仍在，云端授权保持原选择。仅测试此流程不需要发送模型请求。
10. 完成后退出程序。未替换 E 盘原软件，没有迁移旧问卷、修改真实账户配置或上传 GitHub。

## 开发者复现

```powershell
pnpm dist:representative-local
```

该命令先运行全量检查，再生成独立时间戳目录，不覆盖已有验收包。打包禁止自动发布，排除角色模型、账户及密钥，并比较包内文件与当前构建内容。若打包已完成、仅后置审查失败，可在修复审查原因后使用 `node scripts/build-local-acceptance.cjs --finalize <验收目录>`；它不重新打包，也拒绝覆盖已有校验文件。

实际打包程序的完整功能测试需要现有 Playwright 环境。将 `NODE_PATH` 指向工作区提供的 Node 包目录，然后：

```powershell
$env:ECHO_REPRESENTATIVE_PACKAGE_DIR = (Resolve-Path 'release/representative-local-20261015T122509Z').Path
pnpm smoke:representative
Remove-Item Env:ECHO_REPRESENTATIVE_PACKAGE_DIR
node scripts/smoke-local-portable.cjs release/representative-local-20261015T122509Z
node scripts/audit-local-package.cjs release/representative-local-20261015T122509Z
```

新构建时替换为新目录。功能测试启动 `win-unpacked/EchoVerseLauncher.exe`，确认 `app.isPackaged`、实际 ASAR 入口和隔离用户目录；仅在测试进程中注入模拟传输，不修改 ASAR，不包含测试脚本或模拟服务。便携测试另行启动实际 EXE，验证解压、打包启动和正常退出，游戏目标被明确设为不存在，不能据此称为游戏联调通过。

`pnpm test:avatar` 覆盖生产外观加载生命周期的成功、空模型、缺失、图形错误、超时、晚到结果和卸载清理。完整桌面测试验证自然缺少模型时的错误、每次局部重试一次读取、运行时自制几何体成功显示、草稿与隐私状态保留。截图检查覆盖 1440×900、1120×720 和 150% 缩放，不替代真实用户体验与不同机器图形驱动验收。

第六批额外覆盖 200% 缩放、模型失败前已发出的暂停状态、暂停期间持久文件不变、清空恢复学习且草稿保留、撤权后不再显示学习中、旧设置读取竞态和预加载事件白名单。安全暂停标记通过成功结果的外置 `learningPaused` 返回，不进入持久 `state`；当时未处理整页重载边界。第十批按现有刷新后回登录的产品行为明确结束旧登录，不将其称为完整会话恢复。

第七批增加手动清晰与系统强制颜色、原生折叠键盘操作、开关点击标签范围、合成鼠标按压在 10% 播放速度下的检查；并等待首页、世界、社交、资料页完成加载后截图。预览为隔离测试账户，不是用户真实数据。没有实体 iPhone、触控或全产品读屏器认证。

第八批增加有界贴图、方向与对称、中性中心和不发生折返的数学测试。真实 Electron 中使用生产材质对照 scale=0，验证实际背景像素、清晰/系统高对比回退、减少动效、原生输入、尺寸更新和滤镜清理。打包程序的 ASAR 保持未修改；完整旧流程和便携 EXE 启动退出也通过。30 帧空闲采样仅作为当前隔离环境记录，不等价于交互压力测试或真实硬件帧率认证。

第九批新增合帧预算、七类取消/清理的两阶段检查、目标位移/失效/隐藏、12 帧空闲零写入、原生键盘选区和自动化鼠标移动期间 60 帧采样。实际打包程序的 `representative-smoke.json` 包含 `liquidGlassInteraction.enforced: true`；采样只是当前环境记录，不能替代实体触控、跨显卡或真实用户性能验收。首屏脚本约 210.1 KiB，低于既有 225 KiB 预算。

第十批增加状态运行期元数据、临时正文投影、跨模式旧结果、纯取消保持保护、主文档刷新/渲染退出与旧登录请求的确定性检查。实际窗口回归通过临时隐藏、退出恢复、同文档保留、整页刷新登出及重新登录恢复资料，`temporaryPrivacy` 记录结果且新增模型请求为 0。旧测试同时确认临时期间不再读取长期正文、退出后原偏好仍未被临时输入覆盖。
