# Aociety：局部 Liquid Glass 风格材质

2026-10-15，第八批。基于第七批现有界面增强，不重做账户或对话系统。

此文保留第八批材质记录。第九批继续优化高频指针合帧与取消边界，不改变材质外观；前后证据和新增回归见 `UI_LIQUID_GLASS_INTERACTION.md`。

## 本次交付

导航侧栏、页面分段栏、聊天工作区切换栏和输入区加入局部背景折射、方向性边缘高光与即时按压反馈。保留深色、薄荷强调色、系统字体及原有页面布局。标题栏继续使用磨砂材质和 Windows 窗口控制，不修改拖拽区域。

这是真正对下方像素作局部位移的跨平台近似，不是苹果原生 Liquid Glass，也不是完整的物理光线追踪。背景平坦时，折射本来就不明显；不会为展示特效而给正文加条纹或持续移动的背景。

Apple Design 指导材质只用于功能层、交互及时和辅助功能回退；Impeccable 的界面检查采用一轮批量检查、一次统一修正与最终确认。第一次检查发现边缘幅度偏强，统一减弱折射与高光，避免边缘重影和背景折返。没有引入运行依赖、动画库、字体服务、Figma 文件或远程素材。

## 如何实现

- 每个可见玻璃表面按自身几何尺寸生成圆角矩形位移图。约 14 CSS px 的内缘折射，内部保持中性；SVG 将 8 位中性值 128 校正到精确的 0.5，避免整个背景产生亚像素漂移。
- 位移图最长边不超过 512px，单张 RGBA 内存最多 1 MiB；实际位移 scale 不超过 8 CSS px，即单方向最大偏移小于等于 4px。几何变化时重建，不逐帧生成。
- SVG 位移滤镜只作用于背景伪元素。文字、输入控件、隐私说明和 3D 画布均不参与变形。用于编码位移图的 2D canvas 不挂入页面，不采集、绘制或保存用户内容。
- 鼠标移动时，单次 `requestAnimationFrame` 合并更新边缘光位置；静止时无自建常驻渲染循环。触摸不追踪鼠标光，减少动态效果时关闭跟随，保留静态材质。
- 页面隐藏、卸载或切换清晰模式时，释放对应滤镜、观察器和待执行帧。几何图只留当前窗口内存，不进入账户文件、画像、聊天或网络请求。

## 回退与使用

标题栏原有“玻璃 / 清晰”按钮继续有效。手动清晰、系统减少透明、增强对比和强制颜色设置关闭折射，保留既有可读表面、原生控件与键盘焦点。不能创建位移图或不支持滤镜语法时保留原磨砂版本。

本轮不会自动截取桌面或应用内容来探测兼容性。浏览器接受滤镜语法不代表所有显卡驱动均能正确合成，当前打包程序另有实际像素验证；其他机器若出现异常，可直接使用清晰模式。

## 验证与解释

`pnpm test:ui` 同时运行原 UI 基础检查和新增折射数学测试；完整检查继续覆盖账户、隐私、授权、草稿、试答、外观容错、资源政策及包内安全。

`pnpm smoke:representative` 在隔离账户和模拟传输下运行真实 Electron 窗口。新增光学检查会临时放置条纹诊断背景，分别捕获正常折射和同一滤镜 scale=0 的实际像素，断言边缘改变而中心稳定。诊断图不是产品背景，测试结束会删除。还验证尺寸重建、原生输入、指针高光、清晰模式、减少动态效果、高对比与滤镜移除。

整窗截图检查包括聊天、首页、世界、社交、资料和外观页，覆盖 1440×900、1120×720、150% 和 200% 缩放。30 帧采样只记录当前隔离测试窗口的帧间隔，不证明真实交互、跨显卡或所有机器稳定 60fps；软件绘制测试与正式程序的 GPU 路径也不等价。

当前第八批实际打包程序的像素对照结果：内缘区域平均 RGB 通道差约 5.16，约 8.98% 的边缘采样像素差大于 8；中心区域平均差为 0。完整 `pnpm check`、打包程序功能回归、便携包装器启动退出和包内审查均通过。首屏脚本约 209.2 KiB，低于既有 225 KiB 预算。

正式交付以 `LOCAL_ACCEPTANCE.md` 中的新时间戳 EXE、校验值和实际打包程序 smoke 记录为准。首次手工试用先备份 `%APPDATA%\echoverse-launcher`，不要同时运行新旧版本。未签名，不关闭系统防护以绕过风险提示。
