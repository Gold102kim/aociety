# Aociety：iOS 风格玻璃界面改进

日期：2026-10-15。第七批，基于现有 0.6.0 桌面端改进。

此文保留第七批记录。后续第八批已在局部操作层增加真实背景位移折射，见 `UI_LIQUID_GLASS.md`；下文“不含折射”的描述仅指第七批。

## 目标与边界

让用户先安心交流，再逐步了解自己的数字代表。保留已有账户、独立授权、学习暂停、记忆管理、待续草稿、私密试答与外观失败恢复，不用换皮掩盖未实现的能力。

本次借鉴 Apple Design 的材质分层、即时反馈、空间一致性和辅助功能原则。仍为 Windows 上的 React/Electron 应用，不是 iOS 移植，也不是苹果原生 Liquid Glass。没有引入折射着色器、持续移动的背景、额外字体、动画库或运行依赖。

## 视觉方向

沿用深色、薄荷色和已有品牌。将玻璃集中用于导航与操作层，内容使用更安静的高不透明度背景，避免每张卡片都模糊、描粗边或发光。

| 层级 | 用途 | 本次处理 |
| --- | --- | --- |
| 背景 | 提供材料下方的环境色 | 静态、克制的雾蓝与紫色环境光，不持续运动 |
| 玻璃操作层 | 标题栏、侧栏、分段工具栏、输入区 | 半透明、24px 背景模糊、薄高光与柔和阴影 |
| 内容层 | 聊天正文、记忆与资料、世界和社交内容 | 清楚的实色感表面，减少重复边框和玻璃嵌套 |
| 重点与状态 | 主操作、选择、错误、隐私提示 | 既有用户强调色；状态同时包含明确文字 |

基础色：背景 `#0B111C`、内容基色接近 `#141D2B`、主文字 `#F3F6FC`、次文字 `#B3C0D2`。强调色继续使用原有九种偏好颜色，不替用户更改。

字体使用系统字体回退，保留中文字体支持。标题适度收紧字距，正文保持自然字距与舒适行高。圆角按区域层级区分，不让所有元素都变成大胶囊。

## 交互改进

- 导航把 AI 对话放在数字代表分组首位，世界与社交归入探索；原按钮名称、页面与返回能力保留。标题栏使用统一 SVG 图标，保留 Windows 的右侧窗口控制位置。
- 新对话的三条建议进入对话内容区，开始交流后隐藏；侧栏不再用一整张建议卡占空间。建议只填写输入框，不自动发送。
- 临时对话、云端授权、模式、记忆管理、重置和关键后果保持可访问。学习范围与记录保存说明使用原生折叠项；连接失败时展开诊断。不会把授权范围或撤回限制藏进折叠内容。
- 开关保留真实 checkbox 语义与键盘操作，使用 iOS 风格轨道、白色滑块和明确位置变化。标签保留至少 44px 点击高度。
- 主操作按下时缩放至 0.96，120ms 状态反馈；导航只用轻量背景变化。没有等待动画结束才接受操作，也没有新增拖拽或滑动手势。
- 窄窗口与放大时，内容改为单列，侧栏缩窄且可滚动；不缩小或隐藏重要授权文字。

## 验证

`pnpm check` 覆盖类型、账户、隐私、会话隔离、模型请求、草稿、试答、外观生命周期、资源政策、包内安全与构建预算。首屏 JavaScript 约 204.5 KiB，仍低于既有 225 KiB 预算。

桌面回归在隔离账户与模拟传输下运行，使用真实 Windows 系统加密，不调用付费模型、不启动游戏。检查包括：

- 1440×900、1120×720、150% 和 200% 缩放；新旧核心流程继续可用。
- 登录、聊天、私密试答、外观、首页、世界、社交和资料页的实际内容截图。等待懒加载完成后截图，不以等待画面代替页面验收。
- 手动清晰模式、系统高对比与减少动效；高对比下恢复原生 checkbox，选中文字使用系统色与边框。
- 原生折叠项的 Enter 键操作、开关标签点击范围、控件可访问名称。
- 用合成鼠标输入，将按压过渡放慢至 10% 检查呈现值和取消按压；不是实体触摸、触觉反馈或真实 iPhone 验收。
- 正文与次文字在选定深色基底、原有九种强调色按钮上的对比测试。未宣称完成全产品的人工读屏器认证或每个像素的对比审计。

界面检查按一轮批量检查、一次统一修正与确认执行。保留已有三维资源释放和隐藏暂停，不在画布上添加滤镜。

## 未做与下一步

未增加亮色主题、Figma 文件、Canva 素材、通知、签到、云端账户或新的画像维度。当前界面由项目自身组件和 CSS 实现，不为玻璃效果增加远程服务依赖。

外部真实用户可用性、实体触控、跨显卡性能、真实模型相似度、留存提升和 UE 游戏运行仍需单独验收。临时模式在整个窗口强制重载后的既有同步边界未在本轮扩展。

本机交付仍为未签名便携程序，须先备份账户目录，不要与旧版同时运行。实际产物、校验与使用说明见 `LOCAL_ACCEPTANCE.md`。
