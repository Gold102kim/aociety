# 0.4.2 启动与聊天体验优化

日期：2026-10-14

## 启动

主页、伴生、世界、分身、社交与个人主页按需加载。生产构建首屏 JavaScript 约 211.8 KB，上一版约 254.3 KB，减少约 17%；gzip 约 67.6 KB，上一版约 76.8 KB。首屏预算设为 225 KiB，并检查页面分包保持独立。此指标代表首屏代码体积，不代表整机启动时间或 CPU 占用降幅。

已完成资料的账户登录后，过渡从固定 2700 毫秒缩短至 650 毫秒，期间预加载主页。新账户首次完成资料仍保留完整过渡。减少动态效果的系统设置继续受支持。

## 聊天与操作

- Ctrl+Enter 发送，普通 Enter 换行，中文输入法组合期间不触发发送。
- 失败后可点击“重试上一条”，复用同一条玩家消息及原请求上下文。重试不覆盖尚未发送的草稿，也不重复插入玩家消息。
- 发送前保留最近 12 条历史，与主进程原来的上限一致，降低长对话 IPC 传输量；本次会话可见记录保持完整。
- 世界页启动按钮与首页共用忙碌状态，首页详情入口可导航，设置与下载入口有明确反馈。

DeepSeek 的提供商、模型路由、凭据和个人信息发送范围保持原配置。测试采用本地预览和 mock，不请求真实模型。

完整类型、账户、AI、契约、游戏集成、资产、渲染调度、服务启动、聊天快捷键/历史和生产构建检查。
