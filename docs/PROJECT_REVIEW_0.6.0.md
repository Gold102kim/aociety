## 已修复的核心问题

- 登录、资料、AI 回复和启动游戏都捕获会话版本；账号变化后丢弃旧结果及私密旧错误。伴生窗口不复用旧账户资料。
- AI 取消立即中止客户端传输；旧请求结束只能释放它自己的槽，不会解除新请求的并发限制。上游 HTTP 错误不回显响应正文。
- 游戏启动尝试独立拥有新服务/游戏/会话文件。退出只同步回收未交付的本次资源；预先存在服务和已经交付的游戏保留。
- Python 请求按任务分池、有界准入，禁用 SDK 自动重试。超时/取消后，底层仍运行的线程继续占槽，避免新请求无限排队。冷却使用单调时钟与失败版本。
- 硬件阻塞分析通过小型有界工作池运行，避免阻塞 WebSocket 事件循环；返回实际情绪分析结果。模型异常不在 probe 或冷却提示回显密钥/正文。
- 应用生命周期关闭模型客户端与工作池。关闭或超时不保证已开始的远程计算/计费终止，Python 无法强杀运行中的线程。
- OpenClaw 默认使用应用独立运行/状态目录，不复制桌面 Codex 凭据、不扫描其他助手账户、不递归删旧 runtime。显式共享会影响旧助手登录行为，详见 [Python 审查](../PYTHON_SERVICE_REVIEW.md)。
- UE 使用真正 JSON 序列化，统一请求超时/数量限制、弱对象游戏线程回调和卸载取消。磁盘对话按账户/Agent 作用域隔离，不自动导入旧无作用域记录。
- 服务端居民记忆按随机游戏启动作用域隔离，三条居民 API 显式传递；旧/非法作用域不读写历史，LRU 最多 128 个作用域，每居民 12 轮且文本限长，淘汰后的旧请求不会重新污染缓存。该匿名标识不是鉴权。UE 要求完整、显式的模型/来源/路由响应信息，不用请求默认值替代缺失字段。
- Shipping 在服务端票据交换实现前拒绝本地票据；Development 本地校验不是联网鉴权。采集占位模块不再伪造成功，编辑器远程执行/MCP 自动启动和 Android 网络文件服务器默认关闭。
- 敏感扫描按实际 Git 候选清单工作，强制跟踪的敏感文件仍被拒绝；覆盖脚本/配置、失败封闭、符号链接/目录联接和不含原文的告警。
- 已有深色玻璃 UI、清晰模式、可访问性回退、页面按需加载、225 KiB 首屏预算及最高 30 FPS 分身渲染保留，并纳入回归检查。
